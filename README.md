# Entrainement-code-enfant-et-jeune
Site pour apprendre à coder en jouant, des enfants aux adultes.


Je veux créer un site (plus tard une app) pour que les enfants, comme mon petit frère, les collégiens, les lycéens et même les adultes apprennent à coder de façon ludique. Le but : s’amuser à coder, au point que le code remplace les jeux vidéo.
